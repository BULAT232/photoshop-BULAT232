# GrayBit Studio — лабораторные работы №1–3

Веб-приложение на React для просмотра и исследования изображений PNG, JPEG и GrayBit-7 (GB7). Изображение отрисовывается на HTML5 Canvas, а исходные размеры, формат и глубина цвета отображаются в строке состояния.

## Возможности

- выбор файла и drag-and-drop загрузка PNG, JPEG и GB7;
- собственные кодер и декодер несжатого формата GrayBit-7;
- бинарная маска прозрачности в старшем бите GB7;
- экспорт открытого изображения в PNG, JPEG и GB7;
- масштабирование и автоматическое вписывание в рабочую область;
- определение структуры изображения: grayscale, grayscale + alpha, RGB или RGB + alpha;
- независимые миниатюры и включение/отключение каждого цветового канала;
- визуализация единственного альфа-канала как чёрно-белой маски;
- инструмент «Пипетка» с координатами пикселя, RGB и CIELAB D65;
- диалог «Уровни» с общей и поканальными гистограммами;
- линейный и логарифмический масштабы гистограммы;
- независимые точки чёрного, белого и гамма для Master и каждого канала;
- LUT-коррекция с живым предпросмотром, сбросом, отменой и применением;
- неизменяемый исходный RGBA-буфер и отдельный буфер для отображения;
- адаптивный интерфейс для настольных и мобильных экранов;
- тесты формата и автоматическая публикация на GitHub Pages.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

В PowerShell можно использовать `npm.cmd install` и `npm.cmd run dev`. Локальный адрес: `http://127.0.0.1:5173/`.

## Тесты

```bash
npm test
```

## Размещение

После отправки ветки `main` workflow запускает ESLint, тесты, production-сборку и публикует папку `dist` на GitHub Pages. В настройках репозитория необходимо один раз выбрать **Settings → Pages → Source: GitHub Actions**.

Ссылка на приложение: `https://bulat232.github.io/photoshop-BULAT232/`

## Формат GB7

Файл содержит 12-байтовый заголовок и по одному байту на пиксель. Заголовок включает сигнатуру `47 42 37 1D`, версию, флаг маски, ширину и высоту в сетевом порядке байтов и два резервных нулевых байта. Биты 0–6 пикселя хранят оттенок серого, бит 7 — бинарную маску, если её наличие отмечено в заголовке.

## Цветовые вычисления

Превью каналов строятся в градациях серого. Для пипетки координаты события переводятся из CSS-размера canvas в его реальное разрешение. RGB сначала линеаризуется из sRGB, затем переводится через XYZ с белой точкой D65 в CIELAB.

## Уровни

Общая гистограмма рассчитывается по относительной яркости линейного sRGB. В диалоге можно выбрать Master, Gray, Red, Green, Blue или Alpha в зависимости от структуры изображения. Настройки каждого канала сохраняются при переключении списка. Преобразование выполняется через 256-элементные таблицы LUT, не изменяя исходный буфер до нажатия кнопки «Применить».
